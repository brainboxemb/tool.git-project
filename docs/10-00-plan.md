# Plan

## Purpose

This plan records current and future owner work for `tool.git-project`.
Released history belongs in [../CHANGELOG.md](../CHANGELOG.md).

## Current position

The current release candidate is `v0.2.14`. It retains the v0.2.13 managed
launcher, workflow and documentation contracts and fixes bootstrap checkout
detection so an uninitialized bootstrap gitlink directory cannot be mistaken
for the dirty parent worktree.

Portfolio rollout and accepted-baseline sequencing are coordinated from
`brainboxemb.meta` Migration 011. Completed documentation issue #36 and workflow
naming issue #39 remain owner-local history rather than active work.

## Working priorities

When changing this tool:

1. keep the Git bootstrap/update core domain-neutral and Git-only;
2. preserve Windows PowerShell and POSIX shell parity;
3. keep consumer interfaces released and reproducible;
4. prefer one generic mechanism over domain-specific copies;
5. keep optional orchestration separate from the basic Git path;
6. qualify every released capability on the exact release source revision.
